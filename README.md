# NetDriveGuard

Windows x64 网络盘维护与开发主机连接工具，采用 Rust、Tauri 2、Vue 3 和 TypeScript。当前实现位于 `rust/`；根目录的 C# 项目保留作历史参考。

## 功能

- 分别检查服务器端口、盘符映射和共享访问，连续失败后确认离线。
- 按设置取消离线映射、恢复后重连；两项自动操作默认关闭。
- Windows 凭据管理、登录启动、托盘运行、状态提醒和旧配置读取。
- 独立监测开发主机的 SMB、SSH、RDP 服务，无需先配置网络盘。
- 远程连接复用、主副屏定位、普通窗口、最大化、单屏全屏及专用虚拟桌面。
- 动态远程分辨率、连接与断线状态、原始错误码及切换提示。
- 独立数据目录、按来源和级别筛选的事件记录及脱敏诊断。

## 使用

运行 `NetDriveGuard.exe`，需要 Windows x64 和 Microsoft Edge WebView2 Runtime，无需安装 Rust、Node.js 或 .NET。

网络盘在“维护设置”中配置盘符与共享地址；开发主机在“连接设置”中配置地址、服务端口和桌面安排。两个功能分别配置、检测和暂停。具体操作见[使用说明](rust/desktop/USAGE.md)。

默认数据目录为 `%LOCALAPPDATA%\NetDriveGuard`。密码通过 Windows 凭据窗口或凭据管理器处理，不写入普通配置、日志和命令行。

映射取消采用非强制方式，文件占用时保留映射并显示失败原因。开启自动重连后，所选盘符上的其他网络目标可被当前配置替换，本地磁盘不会被覆盖。
