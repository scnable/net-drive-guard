# NetDriveGuard Rust 使用说明

适用于 Windows x64，需要已安装 Microsoft Edge WebView2 Runtime。直接运行 `NetDriveGuard.exe`，无需安装 Rust、Node.js 或 .NET。

## 配置维护目标

主窗口同时显示连接状态和最近事件，底部提供检查、暂停、打开网络盘、隐藏到托盘和退出操作。

在“维护设置 → 常用设置”选择盘符，填写 `\\服务器\共享名`，保存后开始检查。默认仅观察与提醒。需要自动维护时，分别选择“确认离线后取消映射”和“恢复后自动重连”。

仅所选盘符参与维护。开启自动重连后，其他网络目标占用该盘符时按当前配置替换；本地磁盘不会被覆盖。文件被占用导致取消失败时，程序保留映射并显示错误，不强制关闭文件。

“维护设置 → 监控设置”中的“标准”“快速”“节能”使用预设周期；“自定义”允许调整 TCP 间隔、离线确认次数及超时。映射、TCP 与共享按不同周期检查，连续失败达到阈值后才确认离线。恢复正常必须同时取得正确映射和共享访问证据。

## 账号与运行方式

不填写账号时使用当前 Windows 登录凭据。需要其他账号时，先保存目标，再在“维护设置 → 高级设置”输入账号、密码并点击“保存凭据”。凭据绑定盘符和共享地址，存于 Windows 凭据管理器；更换目标不会自动删除旧目标凭据。

“暂停监控”停止新的检查与自动操作；“恢复监控”重新完整核对。关闭窗口后继续在托盘运行，再次启动会显示原窗口。“退出应用”结束维护及其工作进程，不主动取消正常网络映射。

“当前用户登录时启动”创建普通权限的当前用户登录任务，使用 `--background` 启动，不配置崩溃重启。移动程序后通过“将当前程序设为登录启动项”显式更新任务。同名任务归属无法确认时会提示冲突，不覆盖或删除。

## 数据与排错

默认配置与日志目录为 `%LOCALAPPDATA%\NetDriveGuard`。可在全局“设置”中选择其他本地目录，网络盘的“维护设置 → 高级设置”也保留此入口；切换时复制配置与日志，保留原文件，目标目录已有同类文件时拒绝覆盖。网络共享和被维护盘符不能作为数据目录。

可读取旧 C# 版本的 `config.json`、目录指针及兼容凭据键。配置损坏或版本不支持时保留原文件、提示错误并停止监控；修正设置并保存后重新启用。Rust 设置保存为 `settings.json`。更换应用前退出旧实例并停用旧维护脚本，避免多个程序同时管理同一盘符。

“最近事件”集中显示网络盘、主机检测和远程连接的最近 100 条记录，可按来源和级别筛选；网络盘页的事件表保留状态筛选。日志每份最多 5 MiB，保留 3 个归档。“导出脱敏诊断”不包含共享地址、本地数据目录、账号或密码。

Windows 提醒是否显示还受系统通知设置影响。发生映射操作超时时，结果显示未确认，后续检查会核对实际状态。错误码 1219 表示已有不同账号的服务器连接；先处理对应连接，再重试。

## 开发主机与远程桌面

“开发主机”独立配置主机地址和 SMB、SSH、RDP 端口，无需配置网络盘。SMB、SSH 端口设为 `0` 可停用对应检查。服务状态表示端口是否响应，不表示账号已认证或已进入桌面。各服务分别累计失败；所有已启用服务连续三次无响应时提醒，恢复响应后再提醒。

在“连接设置 → 桌面”选择当前桌面或专用虚拟桌面、目标显示器及普通窗口、最大化或单屏全屏。点击“连接开发桌面”打开使用 Windows 远程桌面控件的独立连接窗口；已有本程序管理的同目标窗口时复用。RDP 和 Linux 登录由 Windows 凭据窗口及 Linux 登录界面处理，账号密码不会写入 NetDriveGuard 配置。连接状态区分等待确认、会话已连接、正在恢复和已断开，断开时保留原始错误码。“会话已连接”表示 RDP 连接建立，Linux 用户登录仍由远程登录界面处理；断开后可再次点击连接。

“移到此屏”移动已有连接。指定显示器缺失时使用当前主屏，保留原显示器偏好；显示器变化后，在该远程窗口处于前台时重新定位。远程分辨率随窗口客户区大小调整，移屏和调整窗口大小均复用原连接；远程服务器需支持动态分辨率。

专用桌面通过保存的桌面标识复用，用户已有桌面和窗口保留。Windows 虚拟桌面切换同时影响所有显示器。`Win+Ctrl+←/→` 切换相邻桌面，已有其他桌面时可能需要多次按键；`Alt+Tab` 在本机选择窗口；`Ctrl+Alt+Break` 切换远程窗口的全屏模式。

“自动操作”中的程序启动后打开、主机恢复后打开和每次激活时恢复目标屏幕默认关闭。开启后分别在对应时机执行，不改变网络盘自动维护选项。切换提示默认开启，显示当前窗口约 1.5 秒后消失；远程窗口提示不代表 Linux 登录成功。

开发主机页的“设置”可独立保存语言、状态变化提醒、登录启动和配置与日志目录。关闭 NetDriveGuard 窗口后继续在托盘运行；退出程序保留已经打开的远程客户端和专用虚拟桌面。
